05

Not on the shared list

These exist in only one product, or are product chrome rather than a shared component. They should still have one implementation inside their product.

  • Pagination — Cloud only, with about 10 hand-built versions. Cloud should build one.
  • Charts — Cloud usage only (recharts). They use the chart color roles.
  • Terminal pane — Desktop and Cloud each embed a terminal. It's a host surface, not a component.
  • Pane tab strip, resizable panes, find bar — Desktop canvas only.
  • Avatar — light use (six files in Cloud, none shared in Mobile). Revisit when team features grow.
  • Slider, calendar — one or two settings screens. Use the platform control.
  • KiloClaw chat — a third chat stack in Cloud and Mobile. It should adopt the agent parts above, not keep its own.
  • Reactions, swipe-to-reply, FAB — Mobile chat behaviors. They stay native.
