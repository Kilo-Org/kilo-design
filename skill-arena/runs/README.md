# Skill Arena Runs

Generated round outputs go here. They are created by the local Skill Arena app and committed as historical evidence of how the skills evolve over repeated prompts.

Use:

```text
runs/<round-id>/<condition>/output.html
runs/<round-id>/<condition>/log.txt
```

Each regeneration creates a new round.

Before committing new rounds, scan logs for secrets or unrelated local data. Keep rounds that help explain skill progress; delete noisy or accidental rounds through the arena UI before committing.
